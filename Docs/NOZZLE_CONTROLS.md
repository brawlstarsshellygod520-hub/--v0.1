## 操作

WASD仍依畫面方向移動，滑鼠位置控制朝向／噴射目標。

| 狀態 | 操作 | 結果 |
| --- | --- | --- |
| 尚未拿消防管 | 右鍵第一下 | 拿出噴槍；這次即使按住也不接管或噴射 |
| 已拿出，尚未連接 | 靠近來源後右鍵 | 接上距離2m內、沒有牆阻隔的最近來源；這次按住不噴 |
| 已拿出且連接 | 下一次右鍵／按住 | 噴射；放開停止 |
| 尚未拿消防斧 | 左鍵第一下 | 拿出斧頭；這次按住也不揮砍 |
| 已拿消防斧 | 再點左鍵 | 完成一次揮砍，放開不會取消已開始的這一刀 |
| 已拿消防斧 | 再按住左鍵 | 按住期間反覆揮砍，鬆開完成當前一刀後停止 |
| 已連接但切去斧頭 | 右鍵 | 先切回噴槍，再按一次才噴；不需重新連來源 |

雙鍵同時按時右鍵優先。失焦、暫停、停用會停止並解除連續操作，回來須重新按一下。
F仍保留來源接／換／斷、窗口固定／解除等操作。2026-10-24已移除E安撫：NPC只要有完整安全路線就自行走向出口，不需玩家靠近。沒有新增教學UI。

來源附近只顯示一個最近可接來源的環形提示：金色＝可接、藍色＝目前已接；離開2m或被牆阻擋即隱藏。
沒有候選來源時右鍵接管不會成功，也不能空噴。

## 管線與限制

- 白管由程式產生，接在噴槍後端；前方噴口是另一個獨立接點。管線隨玩家移動平滑更新，不做複雜軟體物理。
- 此場景管長上限3m，達到上限限制移動，不自動斷管。沿用來源／玩家根節點的水平距離近似，不是每一段可視曲線的精密弧長；噴流距離仍6.5m。
- 單窗口路由仍存在：上限計算來源→窗口→玩家的水平折線。現有水箱到西窗約4.8m，已超過3m，因此**目前這個場景配置不能重玩舊13m窗口路線**；未暗中移動來源或放寬上限。
- 尚無一般管線碰撞或自動繞牆；未重做消防斧破門、教學流程、多人或正式人物握持動畫。

## 程式與模型合約

- `LocalPlayerInput.TickPointerCommand`是目前裝置輸入與新測試共用入口，同時傳入Pressed／Held。`FirefighterTools.TickPointer`擁有裝備、接管與動作狀態；原`TickCommand`／`Tick`保留為歷史低階呼叫，不代表目前滑鼠點擊語意。
- `HoseConnection.FindNearestSource`同時提供連接與提示的候選，避免提示與實際接取不同來源。
- `SourceHighlightView`、`HoseView`與工具模型均位於Visual，只讀玩法。關閉來源模型仍可連接、噴射與反應。
- `ArtSource/UserNozzle/source.blend`為匯出當時副本；`export_user_nozzle.py`可重建FBX與轉軸／比例／接點資料。Unity匯入`Art/UserNozzle/nozzle.fbx`，使用`Nozzle.prefab`，不是把柔性消防管也當作FBX。
- 噴槍長約.55m、4247三角形，保留使用者黑色噴槍本體與握把，不重建替代造型。舊Primitive噴槍停用保留。
- Player的`Anchors/Nozzle`與`Anchors/Hose Inlet`在Visual之外。替換模型只調模型及接點，不需修改噴射反應／移動／工具核心。
- `UserNozzleSetup.BatchInstallAndValidate`只在首次接入，重跑不覆寫已存在配置；既有Prefab與GUID保留。
