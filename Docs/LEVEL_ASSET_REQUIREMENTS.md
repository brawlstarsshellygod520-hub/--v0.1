# 《炎上消防隊》住宅關卡素材與交付清單

更新：2026-10-27。範圍是目前單人住宅 Greybox，不包含多人連線、正式教學 UI、主選單或新關卡。**現有替代品已能驗證玩法；下表不是要求全部美術到齊才能繼續。**

最新佔位素材：已依新室內圖製作25種Primitive家具／家電／來源外觀Prefab並擺入六區，金／藍色互動提示已改物件輪廓，不再地面圈。清單、正式模型替換方法與本輪未搬動的玩法位置見 `Docs/HOUSEHOLD_GREYBOX.md`；後續只需替換Visual，不用重新寫來源／反應。

## 你現在需要提供什麼

1. 日後的角色上色版：沿用 `角色1.fbx`、`角色2.fbx` 同一造型；請連同貼圖提供，不要只給引用電腦路徑的 FBX。這輪先由程式端替兩者綁骨架與基本動畫，不需要你另外找動畫檔。
2. 想統一火焰、液體的美術時，提供一張風格參考即可；我們可先製作原型特效，不必先購買素材。若由美術同學製作，依下列交付規格。
3. 若要替換住宅灰盒，優先交門、窗、來源（水箱／油瓶／家用乾粉滅火器）與油鍋；家具與裝飾最後做。不要新增室內不合理的工業供應站、工作臺或儲物櫃。

| 項目 | 目前／本輪配置 | 正式素材尚需 | 優先級 |
| --- | --- | --- | --- |
| 玩家消防員 | **角色2**：長髮模型，沿用基礎色；Generic 骨架、Idle／Walk | 之後提供正式上色版／貼圖；消防員身分的配色由你決定 | 必要、已接入原型 |
| 待救 NPC | **角色1**：貓耳／尾巴白模；Generic 骨架、Idle／Walk | 正式上色版／貼圖 | 必要、已接入原型 |
| 骨架 | Root → Hips → Spine／Chest／Neck／Head；左右上臂、前臂、手、大腿、小腿、腳；髮／眼隨頭、尾巴隨身體 | 不必先做手指、表情、布料、毛髮物理 | 本輪 |
| Idle | 原地、微小呼吸／重心起伏、可循環 | 正式動作可日後覆蓋 | 本輪 |
| Walk | 原地步態，腿與手交替，依實際位移切換／調速 | 走路手感驗收後再調步幅；需要時才另加跑步 | 本輪 |
| 斧頭動作 | 既有斧頭 Pivot 揮砍，不是完整全身持斧動畫 | 持斧姿勢、單次揮砍、連砍銜接；傷害仍由核心計時判定 | 下一批 |
| 噴槍動作 | 既有手持噴槍顯示／噴射邏輯 | 持槍雙手姿勢、噴射 Loop、收放／接來源的簡單動作 | 下一批 |
| NPC 救援 | 路通自動走向出口，無安撫 | 等待／獲救反應可選，不影響走路和尋路 | 可選 |

基本格式：FBX＋可編輯 `.blend`，1 Unity 單位＝1m，+Y 向上、+Z 為臉朝向、腳底 Y=0。玩家目前高 1.6m、NPC 1.5m；模型在 Visual 下，不帶 Collider／Rigidbody／玩法腳本。Root Motion 關閉，Idle／Walk 首尾接續。外觀用 `Speed`、`CycleSpeed` 讀實際移動，不能用動畫事件決定滅火、受擊或 NPC 救援。

若未來換檔包含新拓樸，需重新權重綁定；保留相同骨架、尺度、前向及動作名稱可省去重新接線。不要覆蓋原始來源檔或 `.meta`。UV／Base Color 是上色貼圖版的基本交付；Normal、Metallic／Smoothness 是可選項，現有 Built-in Standard 材質不強求完整 PBR。

## 火焰需要什麼

| 項目 | 已有架構／原型替代 | 要完成畫面的素材與規格 | 優先級 |
| --- | --- | --- | --- |
| 地板火 | FireField 管強度、蔓延、熄滅；目前簡單色塊／火形展示 | 一組可循環火焰 Particle System 或低模動畫 Mesh；強度控制高度／密度，位置以地面為原點 | 下一批 |
| 物件火／油鍋火 | ObjectFire 分普通火、油鍋火；水不能滅油鍋、乾粉可滅 | 與物件接點對齊的小型火焰，同一視覺可調尺寸；不用重寫火邏輯 | 下一批 |
| 煙 | 尚無正式煙效果 | 可選煙霧貼圖／粒子，限制數量；本輪不做煙中毒／通風規則 | 可選 |
| 熄滅反應 | 火強度變小直至消失 | 可選短暫蒸氣／粉末消散；不能先消掉判定再等美術計時 | 可選 |

**火的視覺不擁有傷害、蔓延或碰撞權威。** 換 VFX 只接強度／點燃／熄滅狀態；特效關閉，玩法仍運行。透明特效請附需要的材質、貼圖與排序設定，使用本專案 Built-in 相容 Shader，不先引入新渲染管線。

## 液體與乾粉需要什麼

| 來源 | 已有玩法 | 飛行中需要 | 碰撞／地面需要 |
| --- | --- | --- | --- |
| Water 水 | 獨立射程／散佈／空中與地面壽命、滅火、推力 | 水柱或水珠／流線材質、淡藍或透明可讀外觀 | 短暫水花與濕地面材質／貼花 |
| Oil 油 | 滑地、延長燃燒／影響火勢、獨立停留時間 | 黃色油滴／較稠短噴流 | 油漬／反光，燃燒時讀取既有火狀態，不再私建一套火 |
| Dry Powder 乾粉 | 家用滅火器來源，能滅油鍋、無水推力 | 白色錐狀粉霧，適度遮擋，不蓋住玩家 | 白粉殘留、消散效果；不用液體黏度物理 |

三者已有 SprayProfile，可各自調距離、範圍、AirLifetime、GroundLifetime、流量與效果倍率；目前飛行粒子與地板格子是替代外觀。**不需為新外觀修改反應規則，不以 Particle System Collision 重複觸發一次傷害／滅火。** 視覺按既有飛行樣本和落地反應呈現；停止噴射後空中樣本依原壽命繼續。最少每種一個飛行材質＋一個落地外觀即可，不必第一版就做真實流體。

## 交付資料夾與下一批順序

- 原始模型／可編輯檔放 `ArtSource/<資產名稱>/`；Unity 輸出放 `Assets/FireRescue/Art/<資產名稱>/`，材質與貼圖一起交付。
- Prefab 維持 `Root（核心組件／碰撞） / Anchors（玩法接點） / Visual（可替換外觀）`。骨架只留 Visual 裡，遊戲槍口／管入口不綁動畫骨骼。
- 建議先驗收雙角色 Idle／Walk 與方向 → 雙手持槍／持斧姿勢 → 火焰、水／油／乾粉的可讀性 → 來源、門窗 → 家具。
- 音效（水／油／粉噴射、砍門、破門、腳步）、正式 UI、教學文字、多人同步都不是本輪素材阻塞項，另排工作。現階段不要以增加裝飾掩蓋核心噴射手感。
