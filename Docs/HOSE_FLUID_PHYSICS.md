# 消防管與液體物理修正 — 2026-10-27

最新本機玩家版：`Builds/HoseFluidPhysics/FireRescue.exe`。保留同資料夾全部Data、MonoBleedingEdge與DLL。沒有更新GitHub公開下載。

## 管線

- 先採「遇牆卡管」的保守原型，不自動繞牆角。這是本輪暫定方案，不是已完成真實軟管模擬。
- 現在拉管會檢查來源出口 → 可選窗口固定點 → 噴槍入管點的沿線牆阻。身體能繞過牆角，不代表管線可斜穿那面牆；受阻會限制繼續拉動，退回／改方向或拔管後可離開。
- 管長仍3m。沿用原本根節點XZ平面距離，固定窗口後是兩段折線；不是可見曲線的精確3D弧長。UsedLength已統一同一度量，角色高度不再讓顯示量超過同一限制。
- 受管長／牆阻限制時，移除角色向外累積的移動和水推慣性，不讓它持續和約束對抗；反向與沿邊移動保留。
- 白色管線的鬆弛曲線／插值若碰到已配置牆壁，該段改拉直。換來源直接重建形狀，不從舊來源跨房間慢慢插值。純外觀關閉不影響玩法限制。
- 來源Component停用、GameObject停用／銷毀後，連線不再殘留幽靈拉力。來源仍無限供應、每位玩家各自持有連線，不加容量或共享水量系統。

原窗口根節點仍在 `(-5.2,0,3.6)`、外框與孔洞尺寸都不變。舊固定點在外框，從水箱斜拉過去，會在內牆處偏離孔洞約1.34m；舊管線其實穿了旁邊的牆。

## 液體量

每次噴射的遊戲量現在由 `來源FlowRate × 按住時間` 資助，再分配給離散飛行份數，不再每次起噴免費多一整份。

| 可重現案例（FlowRate=3） | 修正前接收量 | 修正後／應有量 |
| --- | ---: | ---: |
| 一次0.01秒短按 | 0.075 | 0.03 |
| 五次0.01秒短按 | 0.375 | 0.15 |
| 0.05秒連續按住 | 0.225 | 0.15 |
| 單幀0.5秒 | 約0.825 | 1.5 |

- 短按仍立即噴一小份，不新增起噴延遲。同總時間在30／60／120Hz得到相同接收量。
- 鬆手／換來源時，不足一份的尾量以最後已記錄的舊元素／方向／位置／設定補一次。即使舊來源已被銷毀，也不能把舊水變成新油；重複Stop不重複補量。
- 不再截掉超過0.25秒的時間。長幀可把量合併到有限飛行樣本，不建立無限發射迴圈或佇列。
- 每名玩家仍最多256個存活飛行樣本。極端飽和且沒有空位時，以唯讀DroppedAmount記錄未能發出的量，不在稍後或新來源回放；TotalEmittedAmount供診斷。正常Profile每秒樣本數／空中時間下不應常見此上限。
- 這裡的Amount是遊戲反應量，不宣稱真實公升數或完整流體質量守恆；地板逐格作用、每格上限與反應規則沿用。

水／油／乾粉的射程、散佈、空中／地面時間與效果倍率都沒改；滑鼠仍只決定方向。水仍不能滅油鍋、油不滅火、只有水推動玩家／動態物件。液體碰撞掃掠、最近命中及地面殘留核心演算法保留；不是新增流體引擎或正式VFX。

## 架構／設定

- HoseConnection：3m與沿線牆阻、來源連線狀態。新增明確wallOcclusion及hoseInletAnchor引用，只目前TutorialGreybox啟用；舊Prefab未批次重寫。
- FirefighterMotor：接收允許的位置，清除被約束的外向速度；仍由CharacterController負責人物碰撞。
- HoseView：唯讀畫線，不決定碰撞／長度／噴射。
- SprayEmitter：分配FlowRate時間預算、飛行快照及有界容量；ElementReaction／FireField規則不改。
- HoseFluidPhysicsBuilder：只綁当前住宅牆阻與入管點，遷移已知舊窗口固定點；重跑不覆寫自訂窗點，也不改角色／相機／其他關卡配置。
