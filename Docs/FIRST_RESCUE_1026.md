# 第一關：馬桶水救出第一人

2026-10-27。此版是單一救援片段，不是完整第一關或正式美術。

## 執行與驗收

本機執行根目錄 `PlayLatest.cmd`，固定開啟 `Builds/Latest/FireRescue.exe`。
Unity 場景：`Assets/FireRescue/Scenes/FirstRescue1026.unity`，目前唯一啟用的 Build Scene。
舊 `TutorialGreybox`、其他歷史場景與模型留存，不會自動改成新版。

1. WASD 從右下方正門進屋，走到左上方浴室的馬桶附近。
2. 右鍵第一次拿噴槍，放開再按第二次接馬桶水；這兩次不噴水。
3. 走回浴室門外，靠近門口按 **F** 固定導管點。此時門口比馬桶近，會固定管線，不是解除來源。
4. 拉管到客廳上側，朝右上方臥室門口的火噴水。再次右鍵並按住噴射；滑鼠只控制水平方向，游標不指定命中點。
5. 水需要飛行、碰撞、落地，持續噴才會清火；瞄準門洞，打到門框／牆不會隔牆滅火。可前後移動改變落點，不是點火就瞬間命中。
6. 清出門口的安全通道，NPC 自行走出臥室、穿過正門；抵達屋外後消失，GameManager 計數變 1。沒有安撫、沒有搬運 NPC。

自動驗證實際使用的站位約 `(3.15, -0.6)`（XZ），導管點在浴室門口 `(.24, .82)`。這些是開發定位資訊，不顯示在 Game View。
管線仍限制 **5m**（沿用現有 XZ 預算、包含門口之前的一段），遇牆停止，沒有自動繞牆或偷偷增加管長。
F 在門口可解除該導管點；其他位置仍沿用接／換／斷來源操作。
左鍵拿斧／再按揮砍、按住連砍保留；本片段門預設開啟，沒有加入破門教學。

## 水、火與可替換性

`SprayEmitter` 是唯一水包飛行／碰撞權威，`ElementReaction` 套用反應，`FireField` 擁有火場狀態；`FirstRescueEffects` 只讀水包及火場。換掉或關閉呈現不會代替滅火。

本關水設定：`Assets/FireRescue/Settings/FirstRescueToiletWater.asset`。

- PhysicalBallistics 初速 10.5m/s、壓力包分布 65–100%、向下 10 度、重力 9.81、阻力 .08。
- 以解析飛行位置／速度和最多 1/60 秒掃掠碰撞，避免高速穿牆；碰撞只套一次反應。
- 空中存活上限 1.3 秒，碰撞提早結束；落地水漬邏輯保留 8 秒。停止噴射後，已發出的水仍繼續飛行。
- 來源流量資金、來源切換快照、容量上限仍沿用既有規則，事件不額外產水。
- 舊液體 Profile 預設關閉 PhysicalBallistics，保留原作者曲線。物理模式的射程由初速／角度／重力決定，不使用舊的 MinimumRange / MaximumRange 欄位。

三種水呈現已離線比較：BillboardParticles（柔和圓點）、DropletMeshes（有方向的水滴）、Hybrid（混合，預設）。
可在 Gameplay 的 `FirstRescueEffects.Mode` 切換。水花／濕痕只是視覺，不產生第二次傷害；火是共用低面數火苗 Mesh，強度影響大小與輕微閃爍。

NPC 仍用簡單 BFS，規劃格子、格間掃掠與實際移動使用同一 CharacterController 淨空；卡住會停下重判，不會傳送。格子中心對齊實測門洞，避免有效門洞剛好沒有足夠淨空的取樣點。
