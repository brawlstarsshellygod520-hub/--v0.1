# 炎上消防隊 v0.2 Prototype

單人住宅關卡測試版。

## 下載與執行

下載 **`FireRescue-v0.2-Windows-x64.zip`**，完整解壓縮後執行 `FireRescue.exe`。請保留 `FireRescue_Data`、`MonoBleedingEdge` 資料夾與所有 DLL。

## 模型製作與提供

| 內容 | 製作／提供者 |
| --- | --- |
| 第一關地圖、戶型與廚房場景 | 其澔 |
| 馬桶、布丁、油鍋、蘇打粉、消防斧、消防噴槍 | xh |
| 人物角色模型 | 飛魚、風信子 |

## 操作說明

| 操作 | 功能 |
| --- | --- |
| WASD | 依螢幕方向移動 |
| 滑鼠 | 決定方向，不是直接指定命中點 |
| 左鍵 | 首次拿斧；再次揮砍，按住連砍 |
| 右鍵 | 首次拿噴槍；靠近來源再按接管；之後點按／按住噴射 |
| F | 拔管；換來源後用右鍵重新連接 |
| E | 拿起／放下布丁，靠近住戶時交付 |
| R／失敗畫面「重新開始」 | 重開本關 |

持物時不能使用工具，砍門前請先放下布丁。

## 更新重點

- 第一關住宅流程與團隊模型更完整；移除本關舊 AI 美術，保留程式管線、水火與臨時圍牆。
- 移動、基本骨架動畫與持具姿勢更流暢；平常朝移動方向，使用工具才朝滑鼠。相機拉遠、對齊房屋並平滑跟隨。
- **10m 白色 3D 消防管**支援拖拉、繞牆與長度提示；噴射具有飛行時間、重力與碰撞。
- 火勢約 **5 秒**擴散至廚房通道後轉慢；火苗更疏，危險地面保留淡色標記。水清地面火，蘇打粉可滅所有火；油鍋未滅，鍋旁會快速復燃。
- 水碰油鍋會爆燃、炸黑布丁；主角踩火或住戶吃黑布丁會死亡。新增 **60 秒交付期限**、斧頭破門、住戶正門逃生及失敗重開，並修正提示框圓角。

## 第一關玩法

**接馬桶水清路 → 倉庫接蘇打粉滅油鍋 → E 拿正常布丁 → 破門、交付 → 住戶自行逃生。**

請在 60 秒內交付；水不要噴向油鍋，並避開仍在燃燒的地面。

> 以上是遊戲規則，不是真實消防操作教學。
