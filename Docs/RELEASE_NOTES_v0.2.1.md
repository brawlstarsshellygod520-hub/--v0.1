# 炎上消防隊 v0.2.1 Prototype

單人住宅關卡測試版。

本次先提供建置版本，未追加新版 Windows 玩家執行測試。

## 下載與執行

下載 **`FireRescue-v0.2.1-Windows-x64.zip`**，完整解壓縮後執行 `FireRescue.exe`。請保留 `FireRescue_Data`、`MonoBleedingEdge` 資料夾與所有 DLL，不要混用舊版檔案。

## 本次更新

- 移除失敗畫面的重開按鈕，改為小文字 **「按 R 即可重來」**。
- 防止繞行屋外的圍牆改為透明阻擋牆：不再遮畫面，碰撞仍保留。
- 延長水的噴射距離，增加水滴密度與可視大小，讓水流更明顯。消防管仍為 **10m**。
- 靠近來源可用 **E** 直接接管，也保留右鍵接管；**E 同時負責拔管，取消 F**。
- E 優先拿取／放下／交付布丁；拿起物品會自動收工具、拔管，避免被管線綁住。管長不足的提示同步改為按 E。

## 操作

| 操作 | 功能 |
| --- | --- |
| WASD／滑鼠 | 移動／決定工具方向 |
| 左鍵 | 首次拿斧，再次揮砍；按住連砍 |
| 右鍵 | 首次拿噴槍，靠近來源再按接管；接好後點按／按住噴射 |
| E | 拿放／交付布丁；沒有物品互動時，接上或拔除管線 |
| R | 重新開始 |

持物時不能使用工具，砍門前請先放下布丁。

## 第一關玩法

**馬桶水清路 → 倉庫接蘇打粉 → 滅油鍋、拿正常布丁 → 破門並於 60 秒內交付 → 住戶自行逃生。**

水碰油鍋會爆燃、炸黑布丁；主角踩火或住戶吃到黑布丁都會失敗。
