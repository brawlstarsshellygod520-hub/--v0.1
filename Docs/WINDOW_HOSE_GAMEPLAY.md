## 操作規則

- WASD 移動、左鍵揮斧、右鍵噴射保持不變。
- 靠近來源按 F 接管；已接管時，靠近青色窗口按 F 固定管線。
- 在同一窗口再按 F，解除固定但保留來源。遠離所有來源與窗口按 F 才會斷管；在來源旁按 F 仍優先接／換／解來源。
- 每人最多一個固定窗口。換接來源或斷管會清除窗口；窗口停用／刪除後退回原直線規則。
- 管長上限仍是 13m。固定後使用水平 `來源 → 窗口 → 玩家` 折線長度，並以窗口為最後支點限制移動，不因換模型而改變。

## 場景配置

- `Step4 User Layout/Window Hose Test/Bathroom Hose Window`：浴室西側外牆，root `(-8.07,0,2.45)`，窗口導管點 `(-8.07,1.15,2.45)`。
- `Outdoor water target`：西側屋外 `(-10.2,0,5.5)`，普通物件火，可用水熄滅。
- 窗框是 Primitive，位於既有 .8m 剖面牆頂上。原牆與 Collider 保留，玩家不能直接穿窗；沒有修改使用者 `.blend` 或其匯入網格。

## 按 Play 後實際走一遍

1. 從出生點進前門，進浴室靠近馬桶水箱按 F 接水。
2. 離開浴室，繞流理台與乾粉瓶的東側，走進後方房間，再從其西側門進庭院。
3. 穿過獨立小屋南側的空地往西，再沿浴室西側外牆靠近青色窗框，按 F 固定。
4. 沿外牆往北走到木塊普通火，滑鼠指向目標並按住右鍵，直到火熄滅。

Scene View 座標參考（x,z；WASD仍是螢幕方向）：接水 `(-2.3,2.4)` → 出浴室 `(.2,2.4)` → `(2.3,2.65)` → `(5,2.65)` → `(4.99,6.94)` → `(2.53,7.2)` → 庭院 `(.13,7.2)` → `(-8.9,7.2)` → 窗口 `(-8.9,2.45)` → 噴射站位 `(-8.9,5.5)`。

不要從前門出門後立刻左轉：已開門板會阻擋，往南繞開又會超出接水後的13m範圍。這輪未移門、縮小碰撞或增加管長來掩蓋路線問題。

## 玩法與外觀分工

| 檔案／物件 | 責任 |
| --- | --- |
| `HoseWindow` | 可互動距離、固定點引用；不讀 Renderer 或模型名稱 |
| `HoseConnection` | 每位玩家的來源／單一窗口、折線管長與移動約束；保留舊單參數互動 API |
| `LocalPlayerInput` | F 傳入可用窗口清單；不計算路徑或元素效果 |
| `HoseView` | 只呈現來源→窗口→噴嘴；窗口頂點直接固定、其餘點平滑跟隨 |
| `HoseWindow.prefab/Anchors` | Route、Interaction；換模型時保留 |
| `HoseWindow.prefab/Visual` | 可停用／替換的窗框，不含 Collider 或玩法狀態 |

來源容量、火焰、乾粉、水花牆阻、NPC 規則未重寫。戶外目標復用既有 `ObjectFire`／`ObjectFireView`，不是另一套火焰系統。

## 驗證入口與限制

- 首次配置：`FireRescue.Editor.WindowHoseBuilder.BatchInstallAndValidate`；已有 marker 時不覆寫場景。正常使用不需重新安裝。
- 實景測試：`FireRescue.Editor.WindowHoseValidation.BatchRun`；報告與 Game Camera 截圖在 `Docs/Validation/2026-10-22-window-hose`。
- 最終窗口50項、水機制回歸27項、乾粉回歸36項 Play Mode PASS；詳見該目錄 `RESULT.md`。實景走路由共用輸入命令驅動，RMB瞄準經 Game Camera 螢幕座標解析，非直接呼叫熄火API。未測實體鍵鼠或Player build。
- 這是**手動單點固定**，不是繩索軟體物理、整條管線碰撞或自動繞牆。未固定時仍沿用直線；其他牆角仍可能被管線穿過。
- 未加入第二位可操作玩家、網路同步、斧頭破門、教學提示／狀態機或正式美術。窗口狀態由玩家自己的 HoseConnection 持有，並不等於已完成多人。
