# 可編輯模型與原始檔

- `UserProvided/Character1`、`Character2`：使用者FBX原始副本及檢視工具。
- `UserProvided/RiggedCharacters`：以上兩份模型加工出的骨架／Idle／Walk與可編輯Blend，不是AI原創模型。
- `UserProvided/FireAxe`、`Nozzle`、`LevelOne`：使用者消防斧、噴槍與第一關戶型的原始Blend及匯出／檢查資料。
- `AIGenerated/Models`：舊版AI／程式生成角色與家具。
- `Tools`：共用生成、匯出、檢查程式，不是模型。

原始FBX／Blend本次只搬位置、不改內容。歷史metadata中的舊路徑保留為匯入證據；現行位置看 `Docs/ASSET_CLASSIFICATION.md` 與 `Docs/Validation/2026-10-27-asset-classification/guid-migration.json`。
