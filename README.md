# 畢業專題 Unity 專案

目前版本：**v0.1**

使用 Unity `6000.0.32f1` 開啟本資料夾，進入 `Assets/_Project/Scenes/Main.unity` 後按 Play。

## 操作

| 功能 | 鍵盤滑鼠 | 手把 |
|---|---|---|
| 移動 | WASD | 左搖桿 |
| 跑步 | Shift | 左搖桿按下 |
| 蹲下 | Ctrl | 右搖桿按下 |
| 撿起／放下 | F | A／Cross |
| 檢視物件 | 左鍵點物件 | — |
| 轉動視角 | 按住右鍵拖曳 | 右搖桿 |
| 選擇物品欄 | 1／2／3 | LB／RB 切換 |

## 專案結構

- `Assets/_Project/Models`：角色模型
- `Assets/_Project/Scenes`：遊戲場景
- `Assets/_Project/Scripts`：遊戲程式
- `Docs/WORKLOG.md`：逐次工作紀錄
