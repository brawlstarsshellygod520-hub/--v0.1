# 炎上消防隊 v0.2.1 Prototype

消防車沒水了！進入住宅，利用室內來源接管滅火，完成住戶要求並協助她逃生。

本版是單人第一關 Prototype，尚未提供多人連線與逐步教學導引。

## 下載與執行

Windows 玩家版：到 [v0.2.1 Prototype 下載頁](https://github.com/xin-hw/Enjo-Fire-Brigade/releases/tag/v0.2.1-prototype)，下載 **`FireRescue-v0.2.1-Windows-x64.zip`**。先完整解壓縮，**保留 `FireRescue_Data`、`MonoBleedingEdge` 資料夾與所有 DLL 檔案**，再執行 `FireRescue.exe`。

不要只從 ZIP 內單獨開啟 EXE，也不要混用 v0.1 檔案。

## 操作說明

| 操作 | 功能 |
| --- | --- |
| WASD | 依螢幕方向移動 |
| 滑鼠 | 決定工具／噴射方向，不是點哪裡就直接命中哪裡 |
| 左鍵 | 第一下裝備斧頭；之後點按揮一刀，按住可連續揮砍 |
| 右鍵 | 第一下裝備噴槍；靠近來源再按一次接上；之後點按／按住噴射 |
| E | 優先拿起／放下／交付布丁；其餘情況接上／拔除管線，換來源時先拔再接 |
| R | 重新開始本關 |

拿起布丁會自動收工具、拔管；拿著布丁時不能使用工具，要砍門時先按 E 放下。

- 本關不再使用舊 AI 美術模型；保留程式消防管、水火效果與封住屋外捷徑的臨時圍牆。歷史素材留在專案供追溯，不代表本關仍在使用。
- 素材依 `UserProvided`／`AIGenerated` 分類；模型外觀與碰撞、來源、受擊、互動邏輯分開，方便後續換模型。
- 修正沙發配置、降低牆壁金屬感；改為室內出生，減少找不到入口的情況。

### 移動、動畫與相機

- 調整移動速度、短步伐頻率、身體起伏及轉向，讓角色移動更輕快流暢。
- 加入基本骨架、待機／行走動作；平常朝移動方向，使用斧頭或噴槍時才朝滑鼠方向。
- 調整雙手持噴槍、持斧及工具跟隨姿勢，減少不合理晃動與穿模。
- 相機拉遠並對齊房屋正向，保留向下俯視與平滑跟隨。

### 消防管與噴射

- 消防管改為連續白色 3D 管線，用簡化物理呈現拖拉、鬆弛與牆角彎曲，降低遇牆斷裂、突然長出節點的情況；並非完整軟管物理模擬。
- 本關管長 **10m**，到極限時顯示「管線不夠長了！按 F 解除綁定！」。
- 噴射依方向發射，具有飛行時間、重力及碰撞，不再直接命中滑鼠位置；不同來源各自設定射程、範圍及空中／地面停留時間。
- 馬桶水可逐區熄滅地面火、留下短暫濕地；蘇打粉可熄滅所有火種，地面滅火較慢，並留下短暫抑制復燃的粉末。

### 火勢、危險與救援

- 火從油鍋附近向外蔓延，約 **5 秒**覆蓋廚房可燃通道，之後轉慢；不再一開場直接鋪滿火。
- 降低火苗視覺密度、縮窄並保留間距；燃燒地面仍有暖色色塊，危險範圍不會因少畫火苗而消失。
- 地面火與油鍋火分開計算；水能滅鍋旁地面火，但油鍋持續燃燒時會快速復燃。換蘇打粉熄滅油鍋後，才能安全拿布丁。
- 水碰油鍋會爆燃、加劇火勢並把附近布丁炸黑；連續水流不會每幀重複爆炸。
- 主角踩火會死亡、掉落持物；焦黑布丁不能恢復，交給住戶後她會說「好難吃...」，接著中毒死亡並失敗。
- 消防斧可破門，門有耐久，每刀只計一次命中；門破後玩家與住戶都能通過。
- 住戶頭上顯示「好想吃布丁...」；收到正常布丁、油鍋熄滅且路線安全後會自行逃生，修正繞後門的問題，直接走正門。
- 加入上方倒數與 **60 秒布丁交付期限**；正常交付後停止倒數，住戶實際抵達出口才算完成。
- 新增失敗畫面「重新開始」按鈕；重開會重置火勢、管線、死亡、布丁品質及計時。

### 互動資訊

- 移除常駐操作說明及多餘提示，保留倒數、住戶心聲與必要情境資訊。
- 可連接來源與可拿布丁使用物體外輪廓高亮；靠近布丁時在旁邊顯示圓角 **E** 提示，離開或拿起後消失。
- 修正情境提示框的上下圓角方向。

## 第一關玩法說明

目標：**一分鐘內把沒有炸黑的布丁送到住戶手上，再清出安全出口讓她逃生。**

1. 從客廳到浴室馬桶旁：右鍵拿出噴槍，再按一次右鍵接馬桶水。
2. 回廚房邊緣，按住右鍵清出通往倉庫的地面路線。**不要朝油鍋噴水**，以免爆燃、燒黑布丁；不要走進仍在燃燒的區域。
3. 按 E 拔管，沿清出的路去倉庫，靠近蘇打粉按 E 連接，也可用右鍵接管。注意 10m 管長，不夠長時先拔管再移動。
4. 用蘇打粉熄滅油鍋與布丁附近的火。油鍋未滅前，鍋旁地面即使被水滅掉也會快速復燃。
5. 確認安全、布丁沒變黑後按 E 拿起；到住戶房門前先放下，用斧頭砍開門，再拿布丁進房。
6. 倒數歸零前靠近住戶按 E 交付。保持逃生路線安全，住戶走到正門出口後完成第一關。

超時、主角被火燒死或住戶吃到焦黑布丁都會失敗；按 R 再試一次。

> 這是誇張化的遊戲規則，不是真實消防教學，請勿依照遊戲進行現實滅火。
